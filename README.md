# FinPilot

FinPilot is a full-stack personal finance dashboard that I built to help users keep track of their money in one place.

The idea was to go beyond just recording expenses, so I also integrated an AI advisor that can look at the user's financial data and answer questions related to their spending and savings.

## Author

Parv Vajpayi

## What it does

Users can:

- Create an account and log in
- Add and manage expenses
- Set monthly budgets
- Create savings goals
- View their financial data through a dashboard
- Get insights about their spending
- Ask the AI advisor questions about their finances

For example, you can ask the AI advisor things like:

> "Where am I spending the most money?"

> "How can I save more this month?"

The advisor uses the user's financial data as context before generating a response.

**Other**

## Why I built this

I wanted to build a project where I could work with a complete frontend and backend instead of making another basic CRUD application.

FinPilot gave me a chance to work with authentication, MongoDB, REST APIs and React together. I also wanted to experiment with adding AI to an application in a way that actually uses the application's data rather than just adding a separate chatbot.
